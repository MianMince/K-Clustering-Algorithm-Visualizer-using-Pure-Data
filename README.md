# K-Means Clustering

K-means clustering is an unsupervised machine learning algorithm used to partition a dataset into distinct clusters based on feature similarity. The algorithm aims to minimize variance within each cluster and maximize the distance between different clusters.

## Why?

It is a coding challenge as Pure Data code is intended for interactive audiovisual installations and synthesizer setups. This worked as an exercise to refine my algorithmic design skills using a limited and impractical programming language. For example, the absence of for loops meant i had to build every loop from scratch using a metronome paired with a rudimentary counter.

I genuinely became insane making it but I did it.

## Program Features
- Interactive visualization of K-means clustering.
- Visual feedback on clustering performance with real-time updates.

## Quick Start
- Download the MidiSeparator-Simple K-means Clustering.pd file INDIVIDUALLY
- Open using Pure Data app (download at https://puredata.info/downloads)
